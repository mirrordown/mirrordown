The pack lists the image size extension under the name it is published with.

- **Markdown Obsidian Image Size is `saeris.markdown-obsidian-image-size`.** The Marketplace refused the name `markdown-image-size`, which another publisher's extension already has, so the extension was not published and version 0.2.0 of the pack listed an extension that does not exist. The extension has a name of its own now, and the pack lists that one.
