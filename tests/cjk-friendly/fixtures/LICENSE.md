# Third-party test data

The `spec-*.md` fixtures are the test corpus of the CommonMark CJK-friendly Amendments, `testcases/*.md` in https://github.com/tats-u/markdown-cjk-friendly at commit `e7bad674ba512a396b95db23c11c9206291eca99`, split into one case per paragraph. `commonmark.json` is `testcases/commonmark.json` from the same repository at commit `28a76f1189685dd2c4e287321d9f896b1982296d`: every example of the CommonMark 0.31.2 specification with its HTML.
